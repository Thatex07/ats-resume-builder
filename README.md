# ATS-Compatible CV Builder

A React-based CV builder designed to help users create clean, structured, and ATS-friendly resumes.

## Features

- Edit personal information, experience, projects, education, skills, and certifications
- Real-time CV preview while typing
- ATS-friendly single-column resume layout
- Export resume as PDF using browser print functionality
- Reset CV data with confirmation modal
- Simple and user-friendly interface

## Technologies Used

- React
- JavaScript
- HTML
- CSS
